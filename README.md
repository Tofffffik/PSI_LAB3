# Обмен валют — конвертер по курсу Национального банка Молдовы

Лабораторная работа №3 на Python 3.11+ с интерфейсом на CustomTkinter.

- **Конвертер**: сумма, две валюты (кнопка ⇄ меняет их местами), дата
  курса с кнопками ‹ › и «Сегодня», результат и курс одной единицы.
- **Курсы на дату**: таблица всех валют с номиналом и курсом в леях.
- Курс берётся с официального сайта НБМ. Если на выбранную дату курса нет
  (выходной, праздник), показывается последний опубликованный — не дальше
  10 дней назад — с предупреждением.
- **Без сети**: программа предлагает показать последний сохранённый курс и
  помечает, от какой он даты.
- Деньги считаются только в `Decimal`; числа выводятся с пробелом между
  тысячами и запятой, независимо от настроек Windows.
- Курс загружается в фоновом потоке, окно не зависает.
- Светлая и тёмная тема (по системе, переключатель в шапке).

## Установка и запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```

Последний полученный курс хранится в `%LOCALAPPDATA%\fxconv\last-rates.json`.

## Тесты

```powershell
python -m pytest
```

Тесты не ходят в сеть: источник курса и архив подменяются. UI-тесты
открывают настоящее окно за пределами экрана, вводят сумму, выбирают
валюты, нажимают кнопки и проверяют, что показано.

## Устройство

| Модуль | Назначение |
|--------|-----------|
| `fxconv/money.py` | валюта, разбор суммы, пересчёт, вывод чисел |
| `fxconv/bnm.py` | запрос и разбор XML НБМ, ошибки источника |
| `fxconv/archive.py` | сохранённый курс (JSON) |
| `fxconv/provider.py` | поиск курса по датам и откат на архив |
| `fxconv/gui/` | окно с вкладками, цвета и шрифты |
| `main.py` | запуск |

## Ветки

| Ветка | Содержимое |
|-------|------------|
| `01-core` | деньги, источник курса НБМ, архив и выбор курса |
| `02-gui` | окно конвертера и таблица курсов |
| `03-tests` | unit- и UI-тесты, README |

Каждая ветка основана на предыдущей и вливается в `main` отдельным
Pull Request в этом порядке.
